# Matt Pocock skills

Repository-local copies of the 27 supported engineering and productivity skills
from [mattpocock/skills](https://github.com/mattpocock/skills).

- Version: **1.3.2**
- Source revision: `4ae2317ddb22b046e26455e4f9c9b3aaaf62212d`
- Scope: every skill listed in the upstream `.claude-plugin/plugin.json`;
  experimental, miscellaneous, and deprecated skills are excluded.
- Location: `.agents/skills/<name>/`, including each skill's supporting files.
- License: [MIT](LICENSE), copyright Matt Pocock.

These are editable repository files, updated manually after reviewing a newer
upstream release. They do not inherit updates from a globally installed plugin.
The Codex skill installer was used with an explicit source revision and this
repository's `.agents/skills` destination.

The repository setup lives in `AGENTS.md` and `docs/agents/`. Edit those
configuration files to change tracker, labels, or domain-doc conventions.
