## Agent skills

### Issue tracker

Track issues and specs in GitHub Issues for `zrm20/packplanner`. Before reading,
creating, or updating tickets, read `docs/agents/issue-tracker.md`.

### Triage labels

Use the five default triage labels. Before triaging or applying status labels,
read `docs/agents/triage-labels.md`.

### Domain docs

Use a single context: root `GLOSSARY.md` and `docs/adr/`. Before exploring the
codebase or proposing domain changes, read `docs/agents/domain.md`.
